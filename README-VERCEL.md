# LIDAN · пакет для Vercel

Це статичний сайт без сервера та команди збірки. Відеодемо, постер і сторінка політики входять до пакета.

## Перед публікацією

1. Відкрийте `privacy.html` і замініть поля у квадратних дужках на перевірені реквізити володільця даних та офіційний контакт для privacy-запитів.
2. Перегляньте `PRELAUNCH-CHECKLIST.md`: там зібрано решту умов, які треба зафіксувати до приймання оплати.
3. Переконайтеся, що у формі й політиці вказані актуальні контакти та умови пропозицій.

## Розгортання

1. Розпакуйте ZIP-архів.
2. Відкрийте термінал у кореневій папці розпакованого сайту.
3. Запустіть `npx vercel` для preview-розгортання. Після перевірки production-версію можна опублікувати командою `npx vercel --prod`.

Vercel розгортає проєкт із кореневої папки через CLI; збирати статичні HTML/CSS/JS-файли окремо не потрібно. Документація: https://vercel.com/docs/cli/deploy

## Форма заявки

Форма відкриває `https://t.me/lidan_manager` із попередньо заповненою чернеткою. Сайт не надсилає повідомлення й не зберігає поля форми на власному сервері. Користувач перевіряє чернетку та сам надсилає її менеджеру.
